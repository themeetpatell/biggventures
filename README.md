# BiggVentures

**The OS Universe for Startups**

BiggVentures is a modern, cinematic web platform showcasing an integrated ecosystem of AI-native systems designed to support entrepreneurs from "I want to build" to "we scaled globally."

## 🌟 Overview

BiggVentures represents a coordinated stack of integrated systems that form a complete operating system for startups. Each brand in the universe solves specific challenges while working together to create compounding momentum for founders.

## 🚀 Features

- **Modern UI/UX**: Cinematic design with glassmorphism effects, smooth animations, and gradient themes
- **Responsive Design**: Fully responsive across all device sizes
- **Interactive Components**: 
  - Auto-sliding brand carousel
  - Testimonial slider with 3D card effects
  - Animated hero sections
  - Smooth scroll animations
- **Multi-page Navigation**: React Router for seamless page transitions
- **Brand Showcase**: Individual pages for each brand in the universe
- **Contact Integration**: Contact form and social media links
- **Team Section**: Showcase of founders and team members

## 🛠️ Tech Stack

- **React 19.2.0** - UI library
- **React Router DOM 7.9.5** - Client-side routing
- **Framer Motion 12.23.24** - Animation library
- **Tailwind CSS 4.1.17** - Utility-first CSS framework
- **Vite 7.2.2** - Build tool and dev server
- **ESLint** - Code linting

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd biggventures
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🎯 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
